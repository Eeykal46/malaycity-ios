=======================================================================================
LANGKAH 1 — MASUKKAN FOLDER ios/ KE REPO GITHUB
=======================================================================================
Repo perlu di GitHub (percuma untuk repo awam; runner macOS percuma untuk repo awam).
Kalau belum ada repo:
  1. Buat repo baru di github.com (cth "malaycity"), JANGAN tick "Add a README".
  2. Di folder D:\MALAYCITY_FULL, jalankan (ganti URL dgn repo kau):

       git init
       git add .
       git commit -m "iOS launcher Fasa 1"
       git branch -M main
       git remote add origin https://github.com/NAMA/repo.git
       git push -u origin main

  Kalau repo sudah ada: git add . ; git commit -m "iOS launcher Fasa 1" ; git push

  PENTING: fail .github/workflows/ios.yml MESTI ikut serta. Tanpa ia, tiada build.

=======================================================================================
LANGKAH 2 — JALANKAN BUILD
=======================================================================================
  1. Buka repo di GitHub -> tab "Actions".
  2. Kiri: "Bina IPA iOS" -> butang "Run workflow" -> "Run workflow".
  3. Tunggu ~10-20 minit (kali pertama lambat: install xcodegen + bina).
  4. Bila selesai (tanda hijau), klik run itu -> bawah, "Artifacts" ->
     muat turun "McLauncher-ipa" (fail zip berisi McLauncher.ipa).

  Kalau tanda MERAH: klik run -> job "build" -> step yg merah -> hantar teks ralat itu.
  Workflow ini GAGAL SENGAJA kalau launcher/index.html tiada dlm bundle - itu cek
  bahawa HTML benar-benar masuk ke dlm app.

=======================================================================================
LANGKAH 3 — PASANG DI IPHONE (Sideloadly + Apple ID percuma)
=======================================================================================
  1. Di PC (Windows): pasang Sideloadly dari https://sideloadly.io
     dan iTunes dari apple.com (perlu untuk driver peranti).
  2. Sambung iPhone 13 Pro dgn kabel. Tekan "Trust" pada iPhone.
  3. Buka Sideloadly:
       - IPA: pilih McLauncher.ipa
       - Apple ID: e-mel Apple ID kau (PERCUMA, tak perlu bayar USD99)
       - Tekan Start, masukkan kata laluan Apple ID.
  4. Di iPhone: Settings -> General -> VPN & Device Management ->
     pilih profil "Apple Development: <e-mel kau>" -> Trust.
  5. iPhone perlu "Developer Mode":
       Settings -> Privacy & Security -> Developer Mode -> On -> restart.
       (Pilihan ini hanya muncul selepas app pertama dipasang.)
  6. Buka app MALAYCITY. Launcher patut muncul (landscape, pil hitam di atas).

  HAD APPLE ID PERCUMA (sebab ini bukan TestFlight):
    - app tamat selepas 7 hari -> pasang semula dgn Sideloadly
    - maksimum 3 app pada satu masa
    - maksimum 10 app ID baharu setiap 7 hari

CARA AMBIL LOG (kalau app tersangkut / crash)
=======================================================================================
  Tanpa Mac:

       Analytics Data -> cari "McLauncher..." -> kongsi fail.
    2. Atau di PC: pasang "Apple Devices" / iTunes -> lihat log peranti.
  Log app ini bertanda: [MC], [MC_DL], [MC_GPU].
  Web Inspector (kalau nanti ada Mac): Safari -> Develop -> iPhone -> halaman.

=======================================================================================
PERKARA YANG PERLU DIINGAT
=======================================================================================
  - ios/launcher/ ialah SALINAN. Jangan edit di situ: edit
    mobile/app/src/main/assets/launcher/index.html, kemudian build semula
    (preGenCommand menyalin semula setiap kali xcodegen generate).
  - Bundle ID: com.malaycity.mobile.ios. Kalau App ID ini sudah dipakai pada akaun
    Apple kau, tukar dlm ios/project.yml (PRODUCT_BUNDLE_IDENTIFIER).
  - Nama app di skrin: MALAYCITY (CFBundleDisplayName dlm plist).
  - Manifest diambil dari https://malaycity.com/mobile/manifest.json
    (McConfig.manifestURL). Host/port server TIDAK didedahkan ke HTML - sama
    seperti Android (LauncherActivity.java).
  - Sasaran minimum iOS 17.0 (iPhone 13 Pro kau iOS 26 -> OK).

UJIAN (boleh jalan di Windows, tanpa Mac)
